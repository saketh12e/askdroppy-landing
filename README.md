# askdroppy-landing

Concept landing page for **Ask Droppy**, an AI droplet for [Droppy](https://getdroppy.app/). Independent concept, not affiliated with Droppy.

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # static output in dist/
```

Stack: Vite, GSAP ScrollTrigger, Motion, Three.js. Design notes: `docs/DESIGN.md`.
Deploys on Vercel as a static Vite site (build `npm run build`, output `dist`).
